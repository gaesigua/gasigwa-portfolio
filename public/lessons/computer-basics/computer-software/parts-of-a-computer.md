# Parts of a Computer

## 1. The Monitor

- **What it is:** The screen that displays information from the computer.
- **How it works:** It shows text, images, and videos that the computer processes.
- **Types:**
  - **CRT (Cathode Ray Tube):** Old, bulky monitors.
  - **LCD (Liquid Crystal Display):** Flat, thin monitors.
  - **LED (Light Emitting Diode):** Brighter, more energy-efficient than LCD.
  - **OLED (Organic Light Emitting Diode):** Best picture quality, used in high-end devices.

## 2. The Keyboard

- **What it is:** A set of keys used to input text and commands into the computer.
- **How it works:** Each key sends a specific signal to the computer when pressed.
- **Types:**
  - **QWERTY:** The standard keyboard layout.
  - **Ergonomic:** Designed to reduce strain on your wrists.
  - **Mechanical:** Keys have physical switches for a tactile feel.
  - **Wireless:** Connects to the computer without a cable.

## 3. The Mouse

- **What it is:** A pointing device used to interact with the graphical user interface (GUI).
- **How it works:** Tracks movement across a surface and sends signals to the cursor on the screen.
- **Types:**
  - **Optical Mouse:** Uses a light to track movement.
  - **Laser Mouse:** More precise than optical, works on more surfaces.
  - **Trackball Mouse:** The ball is on top, and you roll it with your thumb or fingers.
  - **Wireless Mouse:** Connects without a cable.

## 4. The System Unit (Tower)

- **What it is:** The main box that contains the computer's core components.
- **How it works:** It processes data, stores information, and manages the computer's operations.
- **Key Components:**
  - **Motherboard:** The main circuit board that connects all components.
  - **CPU (Central Processing Unit):** The "brain" that performs calculations.
  - **RAM (Random Access Memory):** Temporary storage for active programs.
  - **Hard Drive/SSD:** Long-term storage for files and programs.
  - **Power Supply:** Converts AC power to DC power for the components.

## 5. Other Common Parts

- **Speakers:** Output sound from the computer.
- **Microphone:** Inputs sound into the computer.
- **Printer:** Outputs digital documents to paper.
- **Scanner:** Inputs physical documents into the computer.
- **Webcam:** Captures video and images.
