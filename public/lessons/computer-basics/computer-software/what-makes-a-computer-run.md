# What Makes a Computer Run

## 1. The Power Supply

- **What it is:** The component that provides electricity to all the other parts of the computer.
- **How it works:** It converts the AC power from your wall outlet to the DC power that the computer components need.
- **Why it's important:** Without power, the computer can't turn on or do anything.

## 2. The Motherboard

- **What it is:** The main circuit board that connects all the components of the computer.
- **How it works:** It acts as the central nervous system, allowing all the different parts to communicate with each other.
- **Key Components:**
  - **CPU Socket:** Where the processor is installed.
  - **RAM Slots:** Where the memory modules are inserted.
  - **Expansion Slots:** For adding graphics cards, sound cards, etc.
  - **Connectors:** For hard drives, USB ports, and other peripherals.

## 3. The CPU (Central Processing Unit)

- **What it is:** The "brain" of the computer that performs calculations and executes instructions.
- **How it works:** It fetches instructions from memory, decodes them, and executes them at high speed.
- **Key Components:**
  - **Cores:** Multiple processing units that can work on different tasks simultaneously.
  - **Clock Speed:** Measures how many instructions the CPU can execute per second (measured in GHz).
  - **Cache:** Fast memory on the CPU for quick access to frequently used data.

## 4. RAM (Random Access Memory)

- **What it is:** Temporary storage for data and programs that are currently in use.
- **How it works:** It stores information that the CPU needs quick access to. The more RAM you have, the more programs you can run at once without slowing down.
- **Key Components:**
  - **Modules:** Sticks of memory that plug into the motherboard.
  - **Speed:** Measured in MHz, determines how fast the CPU can access the data.
  - **Capacity:** Measured in GB, determines how much data can be stored.

## 5. Storage (Hard Drive/SSD)

- **What it is:** Long-term storage for your files, programs, and operating system.
- **How it works:** It retains data even when the computer is turned off.
- **Types:**
  - **Hard Disk Drive (HDD):** Uses spinning magnetic disks to store data (slower, cheaper).
  - **Solid State Drive (SSD):** Uses flash memory to store data (faster, more expensive).
  - **NVMe SSD:** Even faster type of SSD that connects directly to the motherboard.

## 6. The Operating System

- **What it is:** The main software that manages all the hardware and software resources of the computer.
- **How it works:** It provides a user interface, manages files, and allows you to run applications.
- **Examples:**
  - **Windows:** The most common operating system for personal computers.
  - **macOS:** Apple's operating system for Mac computers.
  - **Linux:** An open-source operating system used on servers and personal computers.

## 7. Applications (Apps)

- **What it is:** Programs that perform specific tasks for the user.
- **How it works:** They run on top of the operating system and use its resources to perform their functions.
- **Examples:**
  - **Web Browsers:** Chrome, Firefox, Safari
  - **Word Processors:** Microsoft Word, Google Docs
  - **Spreadsheets:** Microsoft Excel, Google Sheets
  - **Games:** Minecraft, Roblox, Fortnite
