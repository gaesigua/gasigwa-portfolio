Data is transmitted over the internet backbone by breaking it down into small packets that are sent through high-speed 
communication links and routers to their destination.

Q. Define the term "Internet" and differentiate it from "Intranet".

Answer:
Internet: A global network of interconnected computers that communicate using
standardized protocols (TCP/IP). It is publicly accessible worldwide.
Intranet: A private network within an organization that uses Internet technologies
(TCP/IP) but is accessible only to authorized users within the organization.
Key Difference: Internet is public and global; Intranet is private and local to an
organization.

Q. Define the following terms: (a) Web Browser (b) Web Server (c) URL (d) HTTP

Answer:
(a) Web Browser: A software application used to access and display web pages
from the internet (e.g., Chrome, Firefox, Edge).
(b) Web Server: A computer system that stores, processes, and delivers web
pages to clients upon request (e.g., Apache, WAMP, XAMPP).
(c) URL (Uniform Resource Locator): The address used to access a resource on
the internet. Example: https://www.mkur.ac.rw
(d) HTTP (HyperText Transfer Protocol): The protocol used for transferring web
pages on the internet. HTTPS is the secure version.

requests and sends back responses.
Diagram:
 Client ----[Request]----> Server
 Client <---[Response]---- Server

Answer:

Q. What is a Domain Name System (DNS)? Explain its role in the internet.
Answer:
DNS (Domain Name System): A system that translates human-readable domain
names (like www.google.com) into IP addresses (like 142.250.190.78) that computers
use to communicate.
Role: DNS acts as the "phonebook" of the internet. Without DNS, users would have to
remember numerical IP addresses instead of easy-to-remember domain names.

Q. Explain the following internet services: (a) Email (b) FTP (c) WWW (d) Cloud Computing
Answer:
(a) Email (Electronic Mail): A method of exchanging digital messages over the
internet. Uses protocols like SMTP (sending) and POP3/IMAP (receiving).
(b) FTP (File Transfer Protocol): A protocol used to transfer files between a client
and a server over the internet. Uses port 21.
(c) WWW (World Wide Web): A system of interlinked hypertext documents
accessed via the internet using web browsers. Uses HTTP/HTTPS protocol.
(d) Cloud Computing: The delivery of computing services (storage, servers,
databases, software) over the internet ("the cloud") instead of local hardware.
Examples: Google Drive, AWS, Azure.

Q. What is an IP Address? Differentiate between IPv4 and IPv6.
Answer:
IP Address: A unique numerical identifier assigned to every device connected to a
network.
IPv4: Uses 32-bit addresses (e.g., 192.168.1.1). Supports about 4.3 billion
addresses. Written in decimal with 4 octets.
IPv6: Uses 128-bit addresses (e.g., 2001:0db8:85a3::8a2e:0370:7334). Supports
virtually unlimited addresses. Written in hexadecimal with 8 groups.

Q. List and explain any FOUR types of network topologies.
Answer:

1. Star Topology: All devices connected to a central hub/switch. Failure of one
device doesn't affect others.
2. Bus Topology: All devices connected to a single cable (bus). Simple but if the
cable fails, entire network goes down.
3. Ring Topology: Devices connected in a circular loop. Data travels in one direction.
Failure of one device affects the network.
4. Mesh Topology: Every device connected to every other device. Most reliable but
expensive. Used in WANs.

Q. Explain the OSI Model and list its 7 layers.
Answer:
OSI (Open Systems Interconnection) Model: A conceptual framework that
standardizes network communication into 7 layers:
1. Physical Layer: Deals with physical transmission (cables, signals)
2. Data Link Layer: Handles error detection and MAC addressing
3. Network Layer: Manages routing and IP addressing
4. Transport Layer: Ensures reliable data delivery (TCP/UDP)
5. Session Layer: Manages sessions between applications
6. Presentation Layer: Data formatting, encryption, compression
7. Application Layer: Interface for user applications (HTTP, FTP, SMTP)
💡 Memory trick: "Please Do Not Throw Sausage Pizza Away" (from bottom to top)

Q. What is TCP/IP? Name the 4 layers of the TCP/IP model.
Answer:
TCP/IP (Transmission Control Protocol/Internet Protocol): The fundamental communication protocol of the internet that 
defines how data is sent and received.
4 Layers:
1. Network Access Layer (equivalent to Physical + Data Link in OSI)
2. Internet Layer (equivalent to Network in OSI) - IP addressing
3. Transport Layer (same as OSI) - TCP, UDP
4. Application Layer (equivalent to Session + Presentation + Application in OSI) -
HTTP, FTP, SMTP

Q14 Differentiate between LAN, MAN, and WAN.
Answer:
LAN (Local Area Network): Covers a small area like a building or campus. High
speed. Example: Office network.
MAN (Metropolitan Area Network): Covers a city or town. Medium speed.
Example: Cable TV network in a city.
WAN (Wide Area Network): Covers large geographical areas
(countries/continents). Lower speed. Example: The Internet.

Q. What is bandwidth? Differentiate between bandwidth and latency.
Answer:
Bandwidth: The maximum rate of data transfer across a network path. Measured
in bits per second (bps, Mbps, Gbps). Higher bandwidth = more data can flow.
Latency: The time delay between sending and receiving data. Measured in
milliseconds (ms). Lower latency = faster response.
Analogy: Bandwidth is the width of a highway (how many cars can pass at once);
Latency is the speed limit (how fast each car travels).

Q. Explain the role of the following in the internet: (a) Router (b) Switch (c) Modem (d)
Firewall
Answer:
(a) Router: A device that forwards data packets between computer networks. It
determines the best path for data to travel from source to destination.
(b) Switch: A device that connects multiple devices within a LAN and uses MAC
addresses to forward data to the correct device.
(c) Modem: A device that converts digital signals to analog signals (modulation)
and vice versa (demodulation) to enable internet access through telephone/cable
lines.
(d) Firewall: A security system that monitors and controls incoming/outgoing
network traffic based on security rules. Protects networks from unauthorized
access.

Q. What is the difference between HTTP and HTTPS?
Answer:
HTTP (HyperText Transfer Protocol): Transfers data in plain text. Not secure.
Uses port 80.
HTTPS (HTTP Secure): Transfers data in encrypted form using SSL/TLS
certificates. Secure. Uses port 443.
HTTPS is essential for websites handling sensitive data like banking, login credentials,
and personal information.

Q. What is cybersecurity? List 4 common cyber threats.
Answer:
Cybersecurity: The practice of protecting computer systems, networks, and data
from digital attacks, unauthorized access, and damage.
Common cyber threats:
1. Malware: Malicious software (viruses, worms, ransomware)
2. Phishing: Fraudulent emails/websites to steal personal information
3. DDoS Attack: Overwhelming a server with traffic to make it unavailable
4. Man-in-the-Middle: Intercepting communication between two parties
