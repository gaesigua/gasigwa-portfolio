## Introduction to Sets
- **Definition**: A set is a collection of objects, called elements.
- **Examples**:  
  - Pets: \( A = \{Alex, Tippy, Shells, Shadow\} \)  
  - Colors: \( B = \{red, blue, yellow\} \)  
  - Sets of sets: \( C = \{\{a, b\}, \{a, c\}, \{b, c\}\} \)

### Popular Sets
- Empty set: \( \emptyset \)  
- Natural numbers: \( \mathbb{N} = \{0,1,2,3,\dots\} \)  
- Integers: \( \mathbb{Z} = \{\dots,-2,-1,0,1,2,\dots\} \)  
- Rationals: \( \mathbb{Q} \)  
- Reals: \( \mathbb{R} \)  
- Complex: \( \mathbb{C} \)


## Comparing and Combining Sets
- **Subsets**: \( S \subseteq T \) means every element of \( S \) is in \( T \).  
- **Union**: \( A \cup B \) = elements in \( A \) or \( B \).  
- **Intersection**: \( A \cap B \) = elements in both.  
- **Difference**: \( A - B \) = elements in \( A \) but not in \( B \).  
- **Power Set**: \( \text{pow}(A) \) = all subsets of \( A \).

**Quiz**
1. Write the set of vowels in English.  
2. Is \( \{1,2,3\} \subseteq \mathbb{N} \)?  
3. True/False: \( \emptyset \subseteq A \) for any set \( A \).  
4. Find \( \{1,2,3\} \cup \{2,3,4\} \).  
5. Find \( \{1,2,3\} \cap \{2,3,4\} \).  
6. List the power set of \( \{a,b\} \).


## Set Builder Notation
- Define sets using predicates.  
- Example:  
  \[
  A = \{n \in \mathbb{N} \mid n \text{ is prime and } n = 4k+1\}
  \]

**Quiz**  
1. Write the set of even integers using builder notation.  
2. Express the set of real numbers greater than 5.


## Set Equality & Properties
- **Equality**: \( X = Y \) if they contain exactly the same elements.  
- **Properties**:  
  - Distributive laws  
  - De Morgan’s laws

**Quiz**  
1. Show that \( A \cup (B \cap C) = (A \cup B) \cap (A \cup C) \).  
2. Apply De Morgan’s law to \( \neg(P \land Q) \).


## Relations
- **Definition**: A relation from \( A \) to \( B \) is a subset of \( A \times B \).  
- **Examples**: Students and classes, flights between cities, divisibility.  
- **Directed Graphs**: Relations can be represented as graphs.  
- **Properties**: Reflexive, symmetric, antisymmetric, transitive.

**Quiz**  
1. Is “is a sibling of” symmetric?  
2. Is “is less than” transitive?  
3. Draw a directed graph for the relation “likes” among three friends.


## Equivalence Relations & Partitions
- **Equivalence Relation**: Reflexive, symmetric, transitive.  
- Example: Congruence modulo \( n \).  
- **Partitions**: Divide a set into disjoint subsets (blocks).

**Quiz**  
1. Show that equality is an equivalence relation.  
2. Partition \( \{1,2,3,4,5,6\} \) into even and odd numbers.


## Partial Orders
- **Definition**: Reflexive, antisymmetric, transitive.  
- Example: “≤” on numbers.

**Quiz**  
1. Is “divides” a partial order on \( \mathbb{N} \)?  
2. Give an example of a partial order in daily life.


## Functions and Mappings
- **Domain**: Input values.  
- **Range**: Output values.  
- **Co-domain**: Set containing all possible outputs.  
- **Vertical Line Test**: A graph represents a function if every vertical line intersects once.  
- **Composition**: \( (g \circ f)(x) = g(f(x)) \).

**Quiz**  
1. Determine if \( \{(1,2),(1,3)\} \) is a function.  
2. Apply the vertical line test to a parabola.  
3. If \( f(x)=x+1 \) and \( g(x)=2x \), find \( (g \circ f)(3) \).


## Graphical Examples

- Mappings between sets.
